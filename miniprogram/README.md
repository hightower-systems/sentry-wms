# 船厂仓储微信小程序

该目录是船厂现场端的原生微信小程序，复用 Sentry WMS 的账号、角色、仓库权限和
`/api/shipyard` 接口。它不替代现有 Expo 移动端，也不维护第二套业务身份。

## 页面

- 收货任务：读取到货清单和票货，展示指定区域；逐托拍摄吊牌，公网 OCR 识别
  打印字段，同一张原图留证，
  按票货一次确认实收入库。
- 出库任务：读取正式出库单和整票任务，展示物料编码、品名、区域及全部托盘后缀；
  逐托拍照 OCR 后一次确认整票出库。
- 装车确认：整张出库单全部票货已出库且无缺口时，单独记录装车人和装车时间。

## 开发与部署

1. 使用微信开发者工具打开本目录。
2. 在 `project.config.json` 中替换正式小程序 AppID；本地可使用测试号。
3. 登录页填写 API 根地址，例如 `https://wms.example.com/api`。正式环境必须使用
   HTTPS，并将域名加入微信小程序 request/uploadFile 合法域名。
4. 为操作员配置 `RECEIVER` 或 `OUTBOUND` 角色，并确认账号已绑定仓库。页面权限
   分别需要包含 `inbound` 或 `shipyard-outbound`。正式出库的列表、详情、拍照
   识别、整票核销、装车确认和照片下载同时校验角色与 `shipyard-outbound` 页面
   权限，缺少页面权限会返回 `403`。

本项目默认关闭开发者工具的域名校验，仅用于本地联调。生产构建不得依赖这一设置。

## 识别边界

正常页面只调用 `wx.chooseMedia` 相机能力，不调用 `wx.scanCode`，也不读取二维码。
每托拍摄一次，同一张原图上传到 `label-recognition` 接口，既用于公网 OCR，也作为
收货/出库证据。服务端负责字段比对、冲突定位、候选任务和最终核销；客户端不自行
判断识别结果。

吊牌原图会发送至配置的公网 OCR 服务。部署前需设置 `BAIDU_OCR_API_KEY` 和
`BAIDU_OCR_SECRET_KEY`，不得写入仓库。

## 测试

```powershell
npm test
```

测试覆盖一次拍摄、无 `wx.scanCode`、OCR 字段补选托盘后缀、确认请求不含二维码、
以及 `app.json` 声明页面的四件套完整性。
